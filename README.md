# Playground repository to play with agents and MCP

This repository demonstrates how to use Azure OpenAI and Azure AI Foundry to build agent-based solutions with Semantic
Kernel in C# and to use MCP as a tool. It provides examples for experimenting with intelligent agents, prompt
engineering, and orchestration using Microsoft's AI services.

# Prerequisites

- An Azure account with access to Azure OpenAI and Azure AI Foundry services.
- .NET SDK installed on your machine.
- Visual Studio or any C# IDE.
- An MCP instance set up and running.
- Basic knowledge of C# and AI concepts.
- Restore NuGet packages.
- Set up environment variables for Azure OpenAI and Azure AI Foundry credentials and MCP tool.
  
# Getting Started
1. Clone the repository:
   ```bash
   git clone
   ```
2. Navigate to the project directory:
   ```bash
   cd your-repo-name
   ```
3. Open the solution in Visual Studio or your preferred IDE.
4. Restore NuGet packages.
5. Set up environment variables for Azure OpenAI and Azure AI Foundry credentials and MCP tool.
6. Build and run the project.
